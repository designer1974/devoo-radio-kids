# Devoo Radio Kids 🟨

Le radio per bambini e ragazzi di tutto il mondo, in un'app semplice e colorata.

- Solo radio per bambini: canzoni, storie e ninne nanne
- Filtri grandi per tipo (🎵 Canzoni, 📖 Storie, 🌙 Nanna) e per lingua
- Mappa del mondo con un pallino giallo per ogni città
- Preferiti col cuore ❤️ e radio a sorpresa 🎲
- Spegnimento automatico per la nanna
- Suona anche a schermo spento
- 🔴 Registra la radio in ascolto (qualità originale, file .m4a)
- ⏰ Registrazioni programmate: oggi, domani o ogni giorno, anche ad app chiusa

## Scaricare l'app

Apri la pagina **Releases** dal telefono e scarica `DevooRadioKids.apk`.
Ogni modifica crea da sola una nuova versione.

Le radio vengono da [Radio Browser](https://www.radio-browser.info), elenco gratuito e aperto.
